# Product Context

## Business Context
The **Talent Tracking System (LTI)** is designed to streamline recruitment operations for HR teams. It addresses the need for a centralized platform to manage candidate information, track application progress, and coordinate interviews.

## User Personas
-   **Recruiter**: Needs to add candidates, view their details, and move them through the hiring pipeline.
-   **Hiring Manager**: Needs to review candidate profiles and provide feedback on interviews.
-   **Admin**: Manages user roles and system configurations.

## Features & Workflows
-   **Candidate Dashboard**: Overview of all candidates and their status.
-   **Profile Management**: Detailed view of a candidate's resume, contact info, and history.
-   **Process Tracking**: Visual representation of the recruitment funnel (e.g., Applied, Interviewing, Offer, Hired).
-   **Data Persistence**: Reliable storage of all recruitment data in a PostgreSQL database.
