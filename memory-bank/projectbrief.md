# Project Brief

## Vision
To build a comprehensive Talent Tracking System (LTI) that simplifies the recruitment process by managing candidates, interviews, and application workflows efficiently.

## Core Features
1.  **Candidate Management**: Create, read, update, and delete candidate profiles.
2.  **Interview Tracking**: Schedule and track interviews through different stages.
3.  **Application Workflow**: Visualise and manage the progress of candidates through pipeline stages.
4.  **Full-Stack Architecture**: Modern React frontend with a robust Express/TypeScript backend.

## Success Criteria
-   Seamless candidate data entry and retrieval.
-   Reliable database operations via Prisma ORM.
-   Intuitive user interface for recruiters.
-   Maintainable and scalable codebase following best practices (layered architecture).

## Monitoring & Observability
-   **Datadog Integration**: Full observability of backend and frontend.
-   **Infrastructure Monitoring**: CPU, Memory, and Disk usage tracking for EC2.
-   **Dashboards**: Centralized view of system health and metrics.
